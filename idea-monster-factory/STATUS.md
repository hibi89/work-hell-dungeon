# 아이디어 괴물 공장 진행 상태

- 브랜치: `feature/idea-monster-factory`
- 목표: 업무지옥 던전과 별개인 두 번째 재미형 제품 실험을 제공한다.
- 선택 설계: 외부 LLM API 대신 키워드 감지와 로컬 조합을 사용한다. 설치·API 비용 없이 실행하며 아이디어를 외부로 보내지 않는다.
- 구현 범위: 분야 자동 감지/수동 선택, 기록-웹툰·상권 비교·10분 학습 아이디어를 위한 구체화 규칙, 분위기, 돌연변이·3단계 범위 조절, 서로 다른 제품 성격의 후보 3개, 상세 설계서, 복사/Markdown 저장, 로컬 도감 재열기·개별 삭제·전체 삭제.
- 파일: `index.html`, `README.md`, `STATUS.md`, `HANDOFF.md`.
- 정적 검증: 임베디드 JavaScript 파싱 PASS; HTML 파싱 및 31개 고유 ID 확인 PASS.
- 브라우저 검증: Playwright 자동 스모크 미완료. 기본 실행과 설치된 Chromium 경로 재시도 모두 Chromium 바이너리 부재로 실행 전 실패.
- 기능 동작, localStorage, 다운로드, 모바일 레이아웃은 브라우저 실기동 미검증.
- 배포: 하지 않음. 정적 파일을 직접 브라우저에서 실행한다.
- 다음: Chromium이 있는 Windows PC에서 핵심 생성·선택·복사/다운로드·도감 흐름을 확인한다. 사용자 제공 환경에서 샘플 아이디어 세 개와 모바일 폭도 확인한다.
