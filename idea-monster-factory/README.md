# 아이디어 괴물 공장

정리되지 않은 아이디어 한 줄을 서로 다른 성격의 제품 괴물 3개로 부화시키고, 하나를 골라 작은 제품 설계서와 다음 검증 행동까지 만들어 보는 한국어 로컬 웹앱입니다.

## 실행

`index.html`을 Chrome, Edge, Firefox 등 최신 브라우저에서 열면 됩니다. 빌드, 설치, 계정, 서버, API 키가 필요하지 않습니다.

## 왜 로컬 규칙 기반인가

| 방식 | 장점 | 부담·제약 |
| --- | --- | --- |
| 외부 LLM API | 자연어 이해와 결과 다양성이 좋음 | API 키·비용·네트워크가 필요하고 아이디어가 외부 서비스로 전송됨 |
| 로컬 규칙·조합 (선택) | 무료·즉시 실행·아이디어 미전송·고정 비용 없음 | 정해진 분류와 조합을 쓰므로 세밀한 맥락 이해는 제한됨 |

첫 버전은 로컬 방식으로 완결했다. 분야 선택과 키워드 감지, 세 가지 제품 성격, 돌연변이 농도, MVP 크기를 조합한다. 실제 LLM 분석을 했다고 표시하지 않는다.

## 사용 흐름

1. 아이디어를 한 문장 이상 적거나 예시를 누릅니다.
2. 분야와 공장 분위기를 선택하고, 돌연변이 농도와 첫 버전 크기를 조절합니다.
3. 세 개의 개체가 부화하면 카드를 눌러 설계서를 비교합니다.
4. 설계서를 복사하거나 Markdown으로 저장하고, 마음에 드는 괴물만 도감에 보관합니다. 도감에서 다시 열어 전체 설계서를 확인할 수 있습니다.

## 설계서에 들어가는 내용

- 제품 콘셉트, 첫 사용자, 해결할 불편, 시그니처 기능
- 첫 버전 기능 범위와 30초 시연 흐름
- 수익화 실험 아이디어, 약점·범위 주의점
- 사용자를 상대로 확인할 다음 검증 행동
- 기괴함·만들기 쉬움·확장 잠재력 점수

점수와 수익 아이디어는 제품을 비교하기 위한 브레인스토밍 보조값입니다. 시장성·매출·기술 난이도를 검증하거나 보장하지 않습니다.

## 개인 정보와 저장

- 아이디어 입력과 생성은 현재 브라우저 탭 안에서만 처리합니다. 외부 AI/API 호출이나 서버 전송은 없습니다.
- 도감 저장은 사용자가 `＋` 보관 버튼을 직접 누를 때만 브라우저 `localStorage`에 기록됩니다.
- 도감 데이터는 해당 브라우저·기기에만 있으며 자동 동기화되지 않습니다. 도감에서 저장 항목을 다시 열거나 개별 삭제할 수 있고, `도감 비우기`로 전체 삭제할 수 있습니다.
- 아이디어 본문은 자동 저장하지 않습니다. 페이지를 닫으면 입력 칸의 내용은 사라집니다.

## 폴더 구조

- `index.html`: 의존성 없는 앱 전체 (HTML, CSS, JavaScript)
- `README.md`: 실행 및 제품 범위
- `STATUS.md`: 완료·검증·대기 상태
- `HANDOFF.md`: 다음 작업을 위한 상세 인수인계

## 의도한 첫 버전 밖의 항목

외부 AI 키 설정, 로그인·클라우드 동기화, 자동 시장 조사, 결제, 팀 협업, 아이디어의 실현 가능성 판정은 포함하지 않습니다. 더 풍부한 AI 모드는 별도 설계·비용·데이터 흐름 검토 후 추가해야 합니다.
