# 퇴근길드: 업무지옥 던전 생성기

반복 업무를 적으면 던전 지도, 시간 계산, 자동화 레시피로 바꿔 보여주는 한국어 미니 앱입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 설치·서버·API 키가 필요하지 않습니다.

## 기능

- 반복 업무 설명, 수행 주기, 1회 소요 시간 입력
- 업무 키워드에 맞춘 던전 방·보스·자동화 레시피 생성
- 주간 반복 시간과 사용자가 정한 자동화 가능성 비율을 이용한 재미용 추정치
- 텍스트 결과 복사 및 `.txt` 저장
- 브라우저 로컬 처리: 서버 전송과 외부 AI 호출 없음
- 모바일 대응 레이아웃, 키보드 입력, 상태 알림

## 계산과 한계

주간 반복 노동 시간은 `1회 소요 시간 × 주간 수행 횟수`로 계산합니다. 예상 구출 시간은 여기에 사용자가 선택한 상상력 비율을 곱한 값입니다. 이는 자동화 성과 예측이나 견적이 아닌 재미용 시뮬레이션입니다. 업무별 분석은 키워드 규칙과 고정 레시피를 사용합니다.

## 기술

의존성 없는 단일 HTML, CSS, JavaScript. 상태는 저장하지 않고 페이지를 닫으면 입력 내용이 사라집니다.
